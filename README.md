# Convertly — Free Online File Converter & Tools

**Convert files effortlessly.**

Convertly is an all-in-one online toolkit that makes file conversion and everyday file operations simple and convenient. Convert images, compress files, resize images, work with PDFs, and generate or scan QR codes — all in one place.

## ✨ Features

### 🖼️ Image Tools
- **Image Converter** — Convert images between PNG, JPEG, and WebP formats.
- **Image Compressor** — Reduce image file size with customizable size options.
- **Image Resizer** — Resize images according to your preferred dimensions.
- **Batch Converter** — Convert multiple images at once.

### 📄 PDF Tools
- **Image to PDF** — Convert images into PDF documents.
- **Word to PDF** — Convert Microsoft Word documents into PDF format.
- **PDF to Text** — Extract text from PDF documents.
- **PDF to Image** — Convert PDF pages into images.

### 🔳 QR Code Tools
- **QR Generator** — Generate QR codes easily.
- **QR Scanner** — Scan and read QR codes.

## 🚀 Getting Started

You can use Convertly directly in your browser without installing any software.

To run the project locally:

1. Clone the repository:

   ```bash
   git clone 
   ```

2. Open the project folder.

3. Run `index.html` in your browser or use a local development server.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser-based processing
- External JavaScript libraries for document and PDF processing

## 🔒 Privacy

Convertly is designed with privacy in mind. File processing is primarily handled in the browser, so files do not need to be uploaded to a remote server for supported operations.
